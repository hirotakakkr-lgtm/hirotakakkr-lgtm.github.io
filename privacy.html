プライバシーポリシー

「おむすび 〜御結び〜」（以下「当店」）は、自店の Google ビジネスプロフィールを管理するための仕組み「omusubi-gbp」（以下「本アプリ」）について、Google アカウントのデータの扱いを次のとおり定めます。

1. 本アプリを使う人

本アプリは当店の店主が、自分の Google アカウントで、自店の情報を管理するためだけに使います。一般の方に提供するものではありません。

2. 利用する Google のデータ

  • Google ビジネスプロフィール（権限：business.manage）：当店の店舗情報（営業時間・カテゴリ・属性など）の確認と更新、当店に寄せられた口コミの取得と返信の投稿、当店の表示回数などの実績の数字の取得
  • Google スプレッドシート（権限：spreadsheets）：当店が管理するスプレッドシートへの、口コミと実績の数字の記録

3. 利用の目的

当店の店舗情報を正しく保つこと、口コミに返信すること、来店につながる数字を把握することだけに使います。広告、販売、他の目的には使いません。

4. 保存と管理

  • Google の許可情報（リフレッシュトークン）は暗号化し、当店の非公開の保存場所にだけ保管します。
  • 口コミや数字は、当店が所有する Google スプレッドシートにだけ記録します。

5. 第三者への提供

取得したデータを第三者に販売・提供することはありません。

6. 許可の取り消し

許可は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。取り消すと、本アプリは Google のデータにアクセスできなくなります。

7. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から取得した情報の利用と移転は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。
